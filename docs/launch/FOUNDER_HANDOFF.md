## Photo moderation contract

The server sends authenticated HTTPS JSON: `version:1`, stable `requestId` photo UUID plus post revision, `originalImageBase64`, normalized `imageBase64`, post `text`, inclusive fitness context and `requireSpecialistIllegalContentScreen:true`. Endpoint must authenticate `Authorization: Bearer <server-only key>`, be private to Tryumph, support the stable request identifier, use specialist-approved screening/reporting, context-aware moderation and agreed retention/deletion. Return `{decision:'approved'|'review'|'rejected'|'specialist', specialistCleared:boolean}`. Only specialist-cleared approved/review images get ordinary derivative storage. Missing clearance, invalid responses, outages and unavailable processing leave the post unpublished. Ordinary admins cannot preview/approve specialist holds. Do not infer safety from an AI-generated description. This adapter contract is **not provider integration verification**.
